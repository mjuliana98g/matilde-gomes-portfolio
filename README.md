## 🇵🇹 Português

Repositório oficial do meu portfólio pessoal, desenvolvido com uma identidade visual em estilo retro/pixel art. O site funciona como um inventário modular para apresentar o meu percurso profissional, académico e projetos.

### Sobre o Projeto

Este projeto foi criado para marcar a minha transição de carreira para a área de TI (com especialização no ecossistema ServiceNow), unindo a minha bagagem analítica em ciências e investigação à programação web. Projeto Google Stitch: https://stitch.withgoogle.com/projects/10128712943858787012.

### Principais Características

**Design Temático:** Estética pixel art inspirada em jogos clássicos.

**Bilingue:** Disponível em Português (index.html) e Inglês (index-en.html).

**Secções Modulares:**

    Sobre Mim: Apresentação e links diretos (LinkedIn, GitHub, Email, CV).
    Competências: Carrossel interativo com Hard Skills, Soft Skills e Hobbies.
    Educação: Percurso académico e formação atual.
    Experiência: 'Missões' como experiências profissionais, "Extras" como part-times e artigos científicos publicados.
    Projetos: Inventário para projetos em curso e concluídos.

### Tecnologias Utilizadas

HTML5
CSS3 (Flexbox, Grid, Variáveis CSS e Responsividade)

## 🇬🇧 English

Official repository of my personal portfolio, built with a retro/pixel art visual identity. The site works as a modular inventory to showcase my professional background, education, and projects.

### About the Project

This project was created to mark my career transition into IT (specializing in the ServiceNow ecosystem), bringing together my analytical background in science and research with web development. Google Stitch project: https://stitch.withgoogle.com/projects/10128712943858787012.

### Key Features

**Themed Design:** Pixel art aesthetic inspired by classic games.

**Bilingual:** Available in Portuguese (index.html) and English (index-en.html).

**Modular Sections:**

    About Me: Introduction and direct links (LinkedIn, GitHub, Email, CV).
    Skills: Interactive carousel with Hard Skills, Soft Skills, and Hobbies.
    Education: Academic background and current training.
    Experience: "Quests" as professional experience, "Extras" as part-time roles and published scientific articles.
    Projects: Inventory of ongoing and completed projects.

HTML5
CSS3 (Flexbox, Grid, CSS Variables, and Responsiveness)
